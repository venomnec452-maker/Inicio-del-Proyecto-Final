Criterios de Revisión del Proyecto (Slide 15)

Detalle de cómo esta implementación responde a cada punto exigido en el curso

1. HTML Semántico y Accesible

Uso correcto de etiquetas <header>, <nav>, <main>, <section>, <article> y <footer> con atributos aria-label y textos alternativos.

2. Diseño Responsivo

Adaptado para smartphones, tablets y pantallas de escritorio mediante el sistema de rejilla y utilidades de Tailwind CSS (grid-cols-1 sm:grid-cols-2 md:grid-cols-3 lg:grid-cols-4).

3. Código Limpio y Comentado

Estructura modular en archivos separados (app.js, cart.js, styles.css) con documentación de funciones y buenas prácticas.

4. Control de Versiones con Git

Inicialización con git init, archivo .gitignore, commits atómicos y desarrollo en ramas colaborativas (feature/maquetacion-y-carrito).

5. Interactividad con JavaScript

Consumo de API con fetch(), manejo de eventos (click, input, change), renderizado dinámico del DOM y almacenamiento en localStorage.

6. Prototipo & Presentación

Estructura lista para defensa oral con guía didáctica, capturas y justificación de decisiones en el README.md.
